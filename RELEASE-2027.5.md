# Larsen Lupin 2027.5 - Windows

The everyday choices are now **Auto** and **Manual**. Auto retains the automatic
processing already used by the preceding version. Manual keeps that protection
active and enables optional supplementary corrections. New configurations start
in **Auto at 70%**, with extra reductions at zero and analysis at **24 fps**.
Saved project values are respected. Restored legacy Speech/Vocals settings stay
explicit and retain their mapping and behavior; there is no silent audio migration.
Choosing Manual from Auto explicitly resets the three extra reductions to zero
before enabling them, including when an older Auto state has dormant percentages.
Each change is notified to the host. Amount, timings and permanent cuts are kept.
Project restoration, host automation and leaving a legacy profile keep their saved
extra values; they do not trigger this UI-only neutral entry.

The Settings menu copies/pastes the 42 saved parameters, eight permanent cuts and
display preferences. One-time transfer to other detected VST3 instances shows
their number and requires confirmation. Discovery is limited to the same loaded
module and host process, which may include other open projects; isolated host
processes require Copy/Paste. Licences, routing, devices and learned corrections
are excluded. Standalone Apply to all tracks includes Amount and preserves I/O.

The bilingual guide explains the recommended Auto 50-70% starting range,
over-processing risks, acoustic limits and the new commands. The UI stays English.
Processing calculations, audio callbacks, component IDs, parameter ranges and
licensing remain unchanged from the preceding standard candidate. This release
does not claim a newly qualified speech model or universal host/audio acceptance.

## Distribution scope

Windows x64: standalone application, VST3, bilingual manual and English quick guide.
macOS remains the separately published **2027.4** package; no Mac 2027.5 is claimed.
No AAX. Mod is excluded. Earlier comparison references are not removed by this update.

Native build, installation, backups and publication are recorded by the Windows
workshop in its immutable delivery receipts. This source note alone is not proof
of successful compilation, installation or publication.
