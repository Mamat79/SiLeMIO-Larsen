# Larsen Lupin 2027.6 - Windows

New configurations start with a gentle **Manual** setting: main processing at
**70%**, extra Noise reduction **20%**, extra Reverb reduction **10%**, extra
Feedback **0%**, and analysis at **24 fps**. The main automatic feedback protection
still operates when extra Feedback is zero. Auto uses the main processing alone.
Adjust by ear and use the least correction that works for the situation.

The processing panel explicitly labels its extra reductions and shows the main
Amount separately. When extra Feedback is zero, analysis retains approximate
before/after frequency markers, marked with `~`; it does not pretend that they
are direct measurements of additional filter settings.

Choosing Manual from Auto recalls the gentle extra settings before changing mode.
This can add a small audible correction. Amount, timing and permanent cuts stay
unchanged. Project restoration and host automation keep saved values, including
compatible Speech and Vocals settings. For an existing setup, select Auto then
Manual to recall the gentle extras without deleting permanent cuts.

The Settings menu retains complete parameter copying/pasting, permanent cuts and
display preferences. Standalone transfer keeps track I/O independent. The VST3
can transfer once to other detected instances in the same host process, with
confirmation; isolated host processes require Copy/Paste.

The interface is English and the user guide is bilingual French/English.
Windows x64 includes the standalone application and VST3. The separately published
macOS package remains 2027.4, with standalone, AU and VST3.

Existing settings and activation data are preserved. Local verification and
download integrity are checked before the published files become the current
download. Listening feedback on actual voices and acoustic setups is welcome.
