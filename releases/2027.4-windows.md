# Larsen Lupin — Windows 2027.4 / macOS 2027.3

Windows 2027.4 makes free activation and the optional supporter licence clearer. Free audio starts its first activation automatically when online. If needed, use **Free / Support**, beside the book, then **Enable free audio** without entering a name or code. A purchase is not required. The optional permanent supporter licence remains EUR 49; the existing 30-day period and subsequent 5-second launch reminder are unchanged. Already running VST3 audio is not interrupted by that reminder.

The support buttons now fit their full labels and show the price without an encoding artefact. The Windows application interface remains English. The included French/English guide has been updated to 2027.4.

Windows x64 includes the standalone application and VST3. The installer keeps the existing application, VST3 and activation identities and preserves personal settings. Close the application and any host using the VST3 before updating. The existing macOS 2027.3 release, its universal DMG and its guide remain available unchanged; this release contains no new Mac build. Mod 2027.3 is outside this standard update.

## Verification scope

The Windows standalone and VST3 were built locally on the Dell. Five targeted CTests passed on the unchanged processing/licensing inputs. Existing compiled verification modes passed for the plug-in editor, standalone English interface, simulated audio settings and window restoration. The corrected labels were visually checked. Installation replaced Windows 2027.3 with 2027.4; the ten installed payload files matched the qualified package and personal settings and encrypted activation files stayed byte-identical in both measured Windows contexts. Backups were verified before replacement.

These are software and simulated-interface checks. No new production audio A/B, physical audio interface, real DAW host, French native interface or multi-monitor DPI qualification is claimed. The original failed obsolete-label assertion was retained and corrected; historical unrelated failures are not reclassified as passes.
