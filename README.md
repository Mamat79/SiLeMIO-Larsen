# Larsen Lupin — SiLeMI/O

Larsen Lupin is available as a standalone application and an audio plug-in. The interface is in English and the user guide is in French and English.

Version **2027.9** adds the 30-day trial and perpetual licence policy and resizable plug-in windows. Drag the bottom-right corner to resize the main plug-in editor or its analysis window. The main editor preserves its proportions in Classic and Essential. Resize standalone windows using their edges.

Windows x64 includes the standalone application and VST3. The macOS universal package includes standalone, AU and VST3 for Intel and Apple Silicon. macOS 11 is the minimum declared in its metadata. Mac applications use ad-hoc signatures and are not notarized with a Developer ID.

New Windows configurations start in **Manual**, with main processing at **70%**, extra Noise reduction **20%**, extra Reverb reduction **10%** and extra Feedback **0%**. Main automatic feedback protection remains active when extra Feedback is zero. Start gently and adjust by ear; use the least correction that works.

Existing projects and saved values are preserved. To recall the gentle extras in an existing setup, choose **Auto**, then **Manual**. Amount, timings and permanent cuts stay unchanged; double-click Amount to return it to 70%. The Settings menu provides Copy/Paste and confirmed transfer to other detected instances. Isolated host instances require Copy/Paste.

The full trial lasts **30 days from the first online activation**. Open the licence panel with the key beside the book to start the trial or activate a licence and view the time remaining. After access expires, the original audio continues to pass through without processing.

A perpetual licence costs **EUR 49 including VAT**, as a one-time payment for one computer at a time. Existing paid and complimentary licences remain valid. After activation, everyday use works offline. To transfer a licence, deactivate it on the old computer while online, then activate it on the new one. Contact SiLeMI/O for recovery after a computer failure. Reinstallation keeps the same deadline when the protected installation key survives. A full system reinstall can erase that identity.

Existing free users receive a **30-day transition period starting when 2027.9 is published**, as announced on the product page. Keep existing activation data and close the application and any host using the plug-in before updating.
